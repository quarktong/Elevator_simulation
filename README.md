# 山东大学中心校区7号楼电梯仿真系统

基于 SimPy 的离散事件仿真系统，模拟山东大学中心校区7号楼宿舍的电梯运行情况。

## 项目简介

本项目旨在通过离散事件仿真方法，模拟7号楼4部电梯的运行调度，分析不同客流模式下的电梯性能表现，为电梯调度策略优化提供数据支持。

## 功能特点

- **SCAN 调度算法**：电梯采用经典的 SCAN（电梯扫描）调度算法
- **分组服务策略**：电梯分为两组，分别服务奇数层和偶数层（1层除外）
- **客流模式模拟**：支持早高峰、午间返程和非高峰三种客流模式
- **动画可视化**：支持生成仿真过程的动画演示
- **性能统计**：提供平均等待时间、行程时间、电梯利用率等统计指标

## 技术栈

- Python 3.8+
- SimPy 4.x - 离散事件仿真框架
- NumPy - 数值计算
- Matplotlib - 动画可视化

## 项目结构

```
elevator_simulation/
├── config.py               # 仿真配置参数
├── models.py               # 数据模型（乘客、呼叫、电梯状态）
├── elevator.py             # 电梯进程（SCAN调度核心）
├── dispatcher.py           # 调度分配器
├── passenger_generator.py  # 乘客生成器（泊松到达）
├── simulation.py           # 仿真引擎
├── statistics.py           # 统计模块
├── animation.py            # 动画可视化模块
├── main.py                 # 入口文件
└── requirements.txt        # 依赖列表
```

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行仿真

```bash
python main.py
```

### 生成动画

```bash
python main.py --animate --sim-time 300 --output elevator_animation.gif
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| --floors | 楼层数 | 17 |
| --elevators | 电梯数量 | 4 |
| --capacity | 电梯容量 | 12 |
| --sim-time | 仿真时长(秒) | 300 |
| --seed | 随机种子 | 42 |
| --animate | 生成动画 | False |
| --output | 动画输出文件 | elevator_animation.gif |

## 仿真配置

### 建筑参数

- **楼层数**：17层
- **电梯数量**：4部
- **电梯容量**：12人/部
- **服务分组**：E1/E2服务奇数层，E3/E4服务偶数层

### 时间参数

| 参数 | 数值 | 说明 |
|------|------|------|
| t_travel | 2.31s | 单层运行时间 |
| t_open_1 | 10.0s | 1层开门时间 |
| t_open | 6.8s | 其他层开门时间 |
| t_close | 4.0s | 关门时间 |

### 客流模式

| 时段 | 时间范围 | 到达率(人/秒) |
|------|----------|---------------|
| 早高峰 | 07:40-08:00 | 0.50 |
| 午间返程 | 12:05-12:20 | 0.66 |
| 非高峰 | 其他时间 | 0.05 |

## 统计指标

- **平均等待时间**：乘客从呼梯到进入电梯的平均时间
- **最大等待时间**：乘客最长等待时间
- **平均行程时间**：乘客在电梯内的平均时间
- **电梯利用率**：电梯处于运行状态的时间比例
- **吞吐量**：单位时间内完成服务的乘客数

## 动画说明

动画中各元素含义：

- **E1-E4**：4部电梯，颜色表示状态
  - 蓝色/绿色：运行中（奇数/偶数组）
  - 紫色：开门中
  - 灰色：空闲
- **红色圆点**：等待中的乘客
- **橙色圆点**：乘坐中的乘客
- **箭头指示**：电梯运行方向
