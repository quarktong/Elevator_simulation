
# 电梯调度算法优化方案

## 概述

本项目包含两个版本的电梯调度算法：
1. **原版**：基于SCAN算法和同组互斥机制
2. **优化版**：基于任务仓库和智能分配器的深度协作算法

## 文件结构

### 原版文件（保持不变）
- `config.py` - 配置参数
- `models.py` - 数据模型
- `elevator.py` - 电梯类（原版）
- `dispatcher.py` - 调度器（原版）
- `passenger_generator.py` - 乘客生成器
- `simulation.py` - 仿真引擎（原版）
- `statistics.py` - 统计模块（原版）
- `main.py` - 主程序入口

- `task_warehouse.py` - 任务仓库模块
- `smart_assigner.py` - 智能分配器模块
- `elevator_optimized.py` - 优化版电梯类
- `statistics_optimized.py` - 优化版统计模块
- `simulation_optimized.py` - 优化版仿真引擎
- `main_optimized.py` - 优化版主程序入口
- `compare_algorithms.py` - 算法对比测试脚本

## 优化算法特性

### 1. 任务仓库机制
- 统一管理所有待分配的厅外呼叫
- 优先队列按优先级排序
- 历史数据记录和统计

### 2. 智能多因素分配器
**优先级评分公式：**
```
Score = α×等待时间 + β×距离 + γ×负载均衡 + δ×方向一致性 + ε×预测价值
```

**权重动态调整：**
- 高峰期：α=0.35, β=0.2, γ=0.25, δ=0.15, ε=0.05
- 非高峰期：α=0.25, β=0.3, γ=0.15, δ=0.2, ε=0.1

### 3. 双电梯深度协作
- **分离模式**：距离&gt;4层，相反方向，独立服务
- **跟随模式**：距离≤4层，相同方向，接力服务
- **收敛模式**：距离&gt;4层，相同方向，负载均衡重分配

### 4. 批量停靠优化
- 同一楼层多个乘客，一次性处理
- 减少重复停靠次数

### 5. ETA预估
- 基于当前任务队列预估到达时间
- 辅助分配决策

## 新增统计指标

- **同组负载不平衡度**：反映双电梯协作效率
- **任务重分配次数**：优化算法动态调整频率
- **批量停靠比例**：批量停靠的效率提升
- **ETA使用次数**：预测功能使用情况

## 预期改进目标

| 指标 | 目标改进幅度 |
|------|-------------|
| 平均等待时间 | &gt;20% |
| 长等待(&gt;2min)比例 | &gt;50% |
| 同组电梯负载不平衡度 | &lt;10% |
| 系统吞吐量 | &gt;15% |
